Параметры объекта

Приведённые пакеты

Инженерия и отделка — единые ставки на продаваемую площадь. Изменение цен — только в администрировании.
Ставки предварительные по ОПиУ; этажная поправка применяется только к инженерии. Лифты считаются отдельно.

Секции и геометрия

Геометрия и объёмы типового этажа задаются отдельно по каждой секции. Незаданные значения не заменяются нулём. Для общих фундаментов и котлованов указывайте их только в одной секции либо корректируйте результат.

Автоматически рассчитываемые объёмы

Формула, площадь/объём, единая ставка и стоимость по каждой позиции; ручная корректировка не меняет исходные данные.
Секция№Работа / формулаРасчётный объёмКорректировкаРасценкаСтоимостьСтатус
Формулы с отметкой «предварительно» не начисляются без выбора галочки выше либо отдельной корректировки. Пустой объём = нет исходных данных, не 0.

Объёмы и работы оператора

Объём здания либо объём типового этажа выбранной секции × число повторений. Неутверждённые цены исключаются из суммы.
№РаботаЕд.ОбъёмБазаСекцияПовторыПрименениеРасценкаСтоимость
Наружные блоки и квартирные перегородки остаются без утверждённых цен. Армирование ЖБ — 75 000 ₽/т; кирпичная кладка — 18 329,56 ₽/м³. Повторное начисление работ внутри комплексной кладки требует обоснования.

Администрирование расценок

Редактируйте ставки, нормативы и коэффициенты. Рабочие тарифы влияют на расчёт; справочные компоненты укрупнённых пакетов не начисляются отдельно.
КодНаименованиеЕд.Расценка / нормативСтатусИсточник / пояснение
Установить цену недостаточно: для двух неутверждённых комплексов нужно отдельно изменить статус. Справочные инженерные, отделочные и фасадные компоненты не суммируются поверх комплексных ставок.
